## Callout: GFM → Notion-flavored `<callout>` 포팅

[docs/adr/0001](../adr/0001-notion-flavored-callout.md) 결정 반영. callout 을 `> [!NOTE]` 에서 Notion API 의 `<callout icon="…" color="…">` 형식으로 전환.

- `src/webview/extensions/callout.ts` — 노드 속성 `emoji`+`color`(18색), `content: block+`, `preprocessMarkdownCallouts` 가 `<callout>` → `<div data-callout>` (nested 재귀, 내부 markdown 은 markdown-it 로 렌더 후 `&#10;` 인코딩해 단일 라인 → CommonMark blank-line 종료 회피, 코드블록 빈 줄 보존), serialize 는 `state.renderContent` 로 자식 블록 왕복.
- `src/webview/calloutMenu.ts` — `type` 제거, 프리셋 칩(emoji+color) + 18색 스와치 그리드 + 커스텀 이모지.
- `src/webview/blockPicker.ts` — 슬래시 callout 을 `CALLOUT_PRESETS` 기반으로, insert content `block+` 대응(`paragraph`), `convertToCallout` 헬퍼(inline → paragraph 래핑).
- `src/webview/styles/*.css` — callout 스타일을 `data-type` → `data-color` 19색 × 4테마(light/dark/claude/sepia), 메뉴 스와치 스타일 추가.
- `tests/callout.test.ts` — preprocess 파스 방향 8케이스 + 프리셋/색상, 10/10 통과.
- 의존성: `markdown-it`(직접 import 명시) + `@types/markdown-it`, `punycode`(esbuild browser 번들용 userland shim).

### 빌드 함정 기록

`markdown-it` 를 webview 번들에 직접 import 하자 esbuild(`platform: browser`)가 `require('punycode')` 에서 멈춤(context API 에선 error 가 hang 으로 표출). tiptap-markdown 은 pre-bundled dist 라 그동안 안 드러났음. userland `punycode` 설치로 해결.

## 남은 주의점

- **serialize(편집 결과 → markdown) 방향은 런타임 QA 필요.** 단위 테스트는 node 환경이라 에디터를 못 띄워 parse 방향만 검증함. VSCode 에서 F5(또는 Cmd+R 리로드)로 `.md` 열어 callout 편집 → 저장 → `<callout icon color>` 왕복 확인 필요. (확장 호스트 kill 금지, 리로드로.)
- Notion sync 는 아직 미착수(그린필드, 별도 설계 필요).
